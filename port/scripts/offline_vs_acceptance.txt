# Deterministic offline acceptance path on an isolated empty card.
#
# Scene-gated navigation: each block is keyed on the guest state-machine bytes
# (mode/state at 0x80479D30+0x33; see docs/OFFLINE_GAMEPLAY_ACCEPTANCE.md), and
# its frame numbers count from the first retrace the gate matches. This is
# immune to boot-length variance.
#
# The Slippi log-in menu (the main-menu scene reached after answering the
# fresh-card prompt) currently ignores scripted input, so automation runs set
# MELEE_FORCE_SCENE=0x0200: when the guest reaches the main menu, the runtime
# fast-forwards the state machine to the VS character select (the "boot to
# CSS" Gecko-code trick). The scene-gated blocks then drive the CSS, the
# stage select, and the match inputs.
#
